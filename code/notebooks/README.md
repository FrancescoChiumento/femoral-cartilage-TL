This folder contains the notebooks:

 - `augmentation_optimization.ipynb`: to perform automated augmentation optimization for the U-Net image segmentation model using Optuna
 - `hyperparameters_optimization.ipynb`: to performs automated hyperparameter tuning for the U-Net image segmentation model using Optuna
 - `optuna.ipynb`: optimization of both hyperparameters and data augmentation values
 - `training_validation_testing.ipynb`: automatic process for training, validation, and testing for the 2D U-net neural network
